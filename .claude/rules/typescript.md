# TypeScript 设计规则

- 在公共边界显式定义类型：组件 props 和 emits、导出函数、外部输入、共享状态和复杂返回值。
- 对明显的局部变量和表达式优先使用推断；类型标注应澄清契约，而不是复述编译器已知信息。
- 将外部或不可信值视为 `unknown`，使用前先收窄；不可避免的不安全集成代码应隔离在带类型的适配器之后。
- 使用判别联合或精确的领域类型建模状态变体，避免由松散关联的布尔值和可选字段构成状态。
- 当表达同一概念时，优先复用 `src/types/` 中的领域类型，而不是另写平行的内联结构。
- 避免绕过证据的断言。必须断言时，保持范围最小，并使运行时不变量清晰可见。
- 保持函数职责聚焦、返回值可预测。当解析、校验、状态变更和展示因不同原因变化时，将它们分离。
- 可机器检查的语法与类型规则由 ESLint 和 `vue-tsc` 负责；本文件只约束工具无法可靠判定的设计决策。
